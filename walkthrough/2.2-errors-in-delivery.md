# 2.2 – Errors in Delivery (7 marks)

## Given
- `tblInvoices` has `NumberOrdered` (how many the customer asked for) and `NumberDelivered` (how many they got).
- The output box is `redQ2`.

## Asked
1. Go to the first row.
2. Find every row where delivered is **not the same** as ordered.
3. Show the InvoiceID and **how many items are missing**.

## Think first
- "Find **every** row" means **Pattern B**: visit every row.
- "Not the same" in Delphi is `<>`.
- "How many are missing" is a subtraction: **ordered − delivered**.
  For example: ordered 4, delivered 3, so 4 − 3 = **1 missing**.

Plan in plain words:
> Go to the top. For each row: if ordered ≠ delivered, work out the missing items and show them. Move to the next row.

## In the Delphi IDE
1. **F12** to the form.
2. Double-click **2.2 – Errors in Delivery**.

## Build the code step by step

**Step 1: Make a variable** for the missing number. It is a whole number, so it starts with `i`. Put it **above** `begin`:
```delphi
var
  iMissing: Integer;
begin
```

**Step 2: Clear the output box** so old answers disappear:
```delphi
  redQ2.Clear;
```

**Step 3: Write the empty loop first.** Do this before anything else, so you never forget `Next`:
```delphi
  tblInvoices.First;
  while not tblInvoices.Eof do
  begin

    tblInvoices.Next;
  end;
```

**Step 4: Add the check inside the loop**, above `Next`:
```delphi
    if tblInvoices['NumberOrdered'] <> tblInvoices['NumberDelivered'] then
    begin

    end;
```

**Step 5: Inside the `if`, work out the missing number and show it:**
```delphi
      iMissing := tblInvoices['NumberOrdered'] - tblInvoices['NumberDelivered'];
      redQ2.Lines.Add('Invoice ID: ' + tblInvoices.FieldByName('InvoiceID').AsString
        + #9 + 'Items missing: ' + IntToStr(iMissing));
```
- `IntToStr` turns a number into text, so we can join it with `+`.
- `.FieldByName('InvoiceID').AsString` reads the field as text straight away.
- `#9` is a **Tab**. It makes neat columns.

## The whole answer
```delphi
procedure TfrmQ2.btnQ2_2Click(Sender: TObject);
var
  iMissing: Integer;
begin
  redQ2.Clear;
  tblInvoices.First;
  while not tblInvoices.Eof do
  begin
    if tblInvoices['NumberOrdered'] <> tblInvoices['NumberDelivered'] then
    begin
      iMissing := tblInvoices['NumberOrdered'] - tblInvoices['NumberDelivered'];
      redQ2.Lines.Add('Invoice ID: ' + tblInvoices.FieldByName('InvoiceID').AsString
        + #9 + 'Items missing: ' + IntToStr(iMissing));
    end;
    tblInvoices.Next;
  end;
end;
```

## Test it
Look at the sample data: invoice **102** ordered 4 and delivered 3. So your output must include:
```
Invoice ID: 102    Items missing: 1
```
Invoice 101 (5 and 5) must **not** show.

## Common mistakes
- **Forgetting `tblInvoices.Next`.** The program freezes, because it looks at the same row forever. If that happens, press **Ctrl + F2** in Delphi to stop it.
- **Putting `Next` inside the `if`.** Then it only moves when there is an error, and freezes on a good row.
- **Subtracting the wrong way round** (delivered − ordered). You get −1 instead of 1.
- **Forgetting `begin ... end`** around the 2 lines inside the `if`. Without them, only the first line belongs to the `if`.

## Exam tip
This is worth 7 marks, so the marker looks for every piece: First, the loop, Eof, the `if`, the subtraction, the output, and Next. Even if one piece is wrong, the others still earn marks. **Always write something.**
