# 2.6 – Gender Stats (10 marks)

## Given
- `tblCustomers` has an `IDNumber` field. It is **Short Text**, not a number.
- How an SA ID number works:
```
  9 8 0 5 1 2 | 0 3 2 6 | 0 8 5
  Y Y M M D D | S S S S |
  birthday    | gender  |
  digits 1-6  | 7 to 10 |
```
- 0000 to 4999 is **female**. 5000 to 9999 is **male**.
- Example output:
```
Number of Males=2
Number of Females=3
```

## Asked
Count how many customers are male and how many are female, and show both counts.

## Think first
1. Visit **every customer** (Pattern B).
2. For each one, **cut out** digits 7 to 10.
3. Is that number below 5000? Then add 1 to females, otherwise add 1 to males (Pattern D).
4. After the loop, show both counts.

How do we "cut out" digits? With **Copy**:
> `Copy(text, start, how many)`
> `Copy('9805120326085', 7, 4)` starts at position 7 and takes 4, giving `'0326'`.

Count it on your fingers: 9-8-0-5-1-2 are positions 1 to 6, so position **7** is the `0`.

## In the Delphi IDE
1. **F12** to the form.
2. Double-click **2.6 – Gender Stats**.

## Build the code step by step

**Step 1: The variables.**
```delphi
var
  sIDNumber: String;  // the ID is text
  iGender: Integer;   // the 4 digits as a number
  iMales, iFemales: Integer;
```

**Step 2: Clear the box and start the counters at 0.**
```delphi
  redQ2.Clear;
  iMales := 0;
  iFemales := 0;
```

**Step 3: The empty loop first** (on **tblCustomers** this time!):
```delphi
  tblCustomers.First;
  while not tblCustomers.Eof do
  begin

    tblCustomers.Next;
  end;
```

**Step 4: Inside the loop, read the ID and cut out the digits.**
```delphi
    sIDNumber := tblCustomers['IDNumber'];
    iGender := StrToInt(Copy(sIDNumber, 7, 4));
```
`StrToInt` turns `'0326'` into the number `326`, so we can compare it with 5000.

**Step 5: Count.**
```delphi
    if iGender < 5000 then
      Inc(iFemales)
    else
      Inc(iMales);
```

**Step 6: After the loop, show the answer exactly like the example.**
```delphi
  redQ2.Lines.Add('Number of Males=' + IntToStr(iMales));
  redQ2.Lines.Add('Number of Females=' + IntToStr(iFemales));
```

## The whole answer
```delphi
procedure TfrmQ2.btnQ2_6Click(Sender: TObject);
var
  sIDNumber: String;
  iGender: Integer;
  iMales, iFemales: Integer;
begin
  redQ2.Clear;
  iMales := 0;
  iFemales := 0;
  tblCustomers.First;
  while not tblCustomers.Eof do
  begin
    sIDNumber := tblCustomers['IDNumber'];
    iGender := StrToInt(Copy(sIDNumber, 7, 4));
    if iGender < 5000 then
      Inc(iFemales)
    else
      Inc(iMales);
    tblCustomers.Next;
  end;
  redQ2.Lines.Add('Number of Males=' + IntToStr(iMales));
  redQ2.Lines.Add('Number of Females=' + IntToStr(iFemales));
end;
```

## Common mistakes
- **`Copy(sIDNumber, 6, 4)`**: starting one place too early. Count the positions on your fingers!
- **Comparing text with a number**, like `Copy(...) < 5000`. Text and numbers can't be compared, so use `StrToInt` first.
- **Looping through tblInvoices.** The ID numbers are in **tblCustomers**.
- **Showing the counts inside the loop.** Then you get many lines. Show them once, **after** the loop.
- **Spaces in the output.** The example has `Males=2` with no spaces around `=`. Copy it exactly.

## Exam tip
SA ID number questions come up **a lot**. Remember the layout:

| Positions | Meaning |
|---|---|
| 1 to 6 | Birthday (YYMMDD) |
| 7 to 10 | Gender (below 5000 = female) |
| 11 | Citizen (0 = SA citizen) |
| 13 | Check digit |

> An easier trick: you only need **digit 7**. 0 to 4 is female and 5 to 9 is male. But do what the question says, and this question says to use the 4 digits.
