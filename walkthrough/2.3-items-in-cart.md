# 2.3 – Items in Cart

## Given
- A hint: a customer who has **not** cleared their cart has **no invoice**.
- A picture of a yellow **Warning** box saying "You have not cleared your cart".

## Asked
1. Ask for a Customer ID with an **input box**.
2. If that customer has **no** invoice, show a **warning** box.
3. If they **do** have an invoice, show **nothing**.

## Think first
The hint turns this into a search question:
> Look through `tblInvoices` for this CustomerID.
> - Found it? They cleared their cart, so do nothing.
> - Never found it? Show the warning.

That is **Pattern C: search and stop**. We use a **flag** called `bFound`. A flag is a True/False variable that remembers "did I find it yet?".

## In the Delphi IDE
1. **F12** to the form.
2. Double-click **2.3 – Items in Cart**.

## Build the code step by step

**Step 1: Make the variables** above `begin`:
```delphi
var
  iCustomerID: Integer;  // the number the user types
  bFound: Boolean;       // the flag
```

**Step 2: Ask for the ID.**
```delphi
  iCustomerID := StrToInt(InputBox('Items in Cart', 'Enter the Customer ID:', ''));
```
`InputBox` has 3 parts: **('title', 'question', 'starting text')**.
It always gives back **text**, so `StrToInt` changes it to a number.

**Step 3: Set up the search.** The flag starts as False, because we have not found anything yet.
```delphi
  bFound := False;
  tblInvoices.First;
```

**Step 4: The search loop.** It keeps going while there are rows left **and** we have not found it.
```delphi
  while (not tblInvoices.Eof) and (not bFound) do
  begin
    if tblInvoices['CustomerID'] = iCustomerID then
      bFound := True
    else
      tblInvoices.Next;
  end;
```
- Use **brackets** around each part of `and`. Without them, Delphi gets confused.
- **No `;`** before `else`! This is the most common error.

**Step 5: After the loop, check the flag.**
```delphi
  if not bFound then
    MessageDlg('You have not cleared your cart', mtWarning, [mbOK], 0);
```
`MessageDlg` has 4 parts:
| Part | Meaning |
|---|---|
| `'You have not...'` | the message |
| `mtWarning` | the type, which gives the yellow triangle ⚠️ |
| `[mbOK]` | the buttons, here just OK |
| `0` | help number (always 0 for us) |

## The whole answer
```delphi
procedure TfrmQ2.btnQ2_3Click(Sender: TObject);
var
  iCustomerID: Integer;
  bFound: Boolean;
begin
  iCustomerID := StrToInt(InputBox('Items in Cart', 'Enter the Customer ID:', ''));
  bFound := False;
  tblInvoices.First;
  while (not tblInvoices.Eof) and (not bFound) do
  begin
    if tblInvoices['CustomerID'] = iCustomerID then
      bFound := True
    else
      tblInvoices.Next;
  end;
  if not bFound then
    MessageDlg('You have not cleared your cart', mtWarning, [mbOK], 0);
end;
```

## Test it
| Type in | What should happen | Why |
|---|---|---|
| `4` | Warning box | The question's example says customer 4 has no invoice |
| `2` | Nothing | Customer 2 has invoices 101 and 102 |

## Common mistakes
- **Using `ShowMessage`.** It shows no warning triangle, so you lose the mark for "warning message dialogue box".
- **Checking the flag *inside* the loop.** Then the warning shows for every row that does not match. Check it **after** the loop, once you have looked at everything.
- **`;` before `else`** gives an error.
- **Typing letters** in the box crashes `StrToInt`. The question does not ask you to stop this, so it is fine in the exam.

## Exam tip
Words like **"verify", "check if" or "exists"** almost always mean **search with a flag**.
