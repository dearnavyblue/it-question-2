## How every walkthrough is laid out

1. **Given:** what the question gives you.
2. **Asked:** what you must do.
3. **Think first:** work out the plan in plain words *before* typing.
4. **In the Delphi IDE:** what to click and type.
5. **Build the code step by step:** small pieces, so you can see how it grows.
6. **Test it:** how to tell if your answer is right.
7. **Common mistakes** and an **exam tip**.
