# 2.1 – Add Record (3 marks)

## Given
- A table called `tblInvoices`.
- The values for a new row: InvoiceID 105, CustomerID 5, NumberOrdered 10, NumberDelivered 10, OnlineTransaction True.

## Asked
Put this new row into `tblInvoices`.

## Think first
"Add a row" means **Pattern A**: make a row, fill it in, save it.

That is 3 steps, and the question is worth **3 marks**. Often each step is one mark.

## In the Delphi IDE
1. Press **F12** to see the form.
2. Double-click **2.1 – Add Record**.
3. Delphi makes `btnQ2_1Click`. Your cursor is inside it.

## Build the code step by step

**Step 1: Make a new empty row.**
```delphi
  tblInvoices.Append;
```

**Step 2: Fill in each field.** The field names must be spelt *exactly* like the table: look at the picture of the table in the question.
```delphi
  tblInvoices['InvoiceID'] := 105;
  tblInvoices['CustomerID'] := 5;
  tblInvoices['NumberOrdered'] := 10;
  tblInvoices['NumberDelivered'] := 10;
  tblInvoices['OnlineTransaction'] := True;
```
- Numbers have **no** quotes: `105`, not `'105'`.
- True has **no** quotes: `True`, not `'True'`.

**Step 3: Save it.**
```delphi
  tblInvoices.Post;
```

## The whole answer
```delphi
procedure TfrmQ2.btnQ2_1Click(Sender: TObject);
begin
  tblInvoices.Append;
  tblInvoices['InvoiceID'] := 105;
  tblInvoices['CustomerID'] := 5;
  tblInvoices['NumberOrdered'] := 10;
  tblInvoices['NumberDelivered'] := 10;
  tblInvoices['OnlineTransaction'] := True;
  tblInvoices.Post;
end;
```

## Test it
1. Press **F9**.
2. Click **2.1 – Add Record**.
3. Look at the **tblInvoices** grid. A new row with **105** should appear.

## Common mistakes
- **Forgetting `Post`.** The row looks added, but it is never saved.
- **Spelling a field name wrong**, like `'NumberOrder'`. You get the error "Field not found".
- **Clicking the button twice.** The second click gives an error, because InvoiceID 105 is already there and every InvoiceID must be different (it is the **primary key**). That is not a bug in your code.
- **CustomerID 5 must exist** in `tblCustomers`. The tables are linked, so the database will not accept an invoice for a customer who does not exist.

## Exam tip
The question does not say to show a message, so **don't add one**. Extras earn no marks.
